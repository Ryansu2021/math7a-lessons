# 國中數學七上 · 有旁白的互動課程

跟著旁白看數字拆開、排好，再在畫面上做隨堂練習。每一節都是一段有配音、有動畫、可以暫停與重播的課程，隨堂練習會即時回饋，最後有成績卡。

線上觀看：https://ryansu2021.github.io/math7a-lessons/

## 目前的內容

| 節 | 主題 | 內容 |
|---|---|---|
| 2-1 | 質因數分解 | 質因數、樹狀圖、算術基本定理、短除法、標準分解式 |
| 2-2 | 最大公因數與最小公倍數 | 列舉、標準分解式、短除法、互質、兩數乘積 |
| 2-3 | 分數的四則運算 | 等值分數、最簡分數、比較大小、加減乘除、倒數、分配律 |
| 2-4 | 指數律 | 分數與負數的乘方、同底數相乘相除、乘方的乘方、乘積的乘方、0 次方 |
| 3-1 | 代數式的化簡 | 以文字符號列式與簡記、求代數式的值、項與係數、同類項、合併同類項、去括號 |
| 3-2 | 一元一次方程式 | 列式、方程式的解、等量公理（天平）、驗算、移項法則、含括號與分數的方程式 |

## 使用方式

- 建議用電腦或平板**橫放**觀看。
- 空白鍵播放／暫停，← → 切換段落，C 開關字幕，< > 調整速度。
- 隨堂練習可以直接點選或輸入答案，進度會記在瀏覽器裡。

- 課程內容、例題與旁白：依 108 課綱七年級上學期設計，例題為自編，不複製教科書內容。
